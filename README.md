## ⚡ Project Overview

This repository houses a high-fidelity, responsive, cyberpunk-inspired developer portfolio designed to showcase academic milestones, core system proficiencies, and hand-picked development works. The design reflects a futuristic terminal atmosphere, leveraging custom animations, neon gradients, glassmorphism, and a custom particle engine.

### 🌟 Key Visual & Interactive Features
*   **Custom Particle Engine**: Dynamic background nodes rendering floating computational particles interactively.
*   **Glitch & Typewriter Effects**: Real-time cyberpunk text animations rendering headers and sub-elements.
*   **3D Interactive Tilt**: Sleek hover transitions on cards that mimic physical depth and perspective.
*   **Lerped Custom Cursor**: A customized ring-and-dot dual cursor system that dynamically expands and shifts color during interactive hover events.
*   **Diagonal Cut-Path Accents**: Buttons and elements crafted with geometric cyberpunk cuts and neon box-shadow glows.

## 🔧 Getting Started & Local Deployment

This project uses **Vite** for optimized assets bundling and hot module replacement (HMR).

### Prerequisites
Make sure you have Node.js and npm installed on your system.

### 1. Clone the Repository
```bash
git clone https://github.com/majay00/personal_portfolio.git
cd personal_portfolio
```

### 2. Install Dev Dependencies
```bash
npm install
```

### 3. Launch Development Server
Starts the Vite dev server locally.
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### 4. Build for Production
Compiles and minifies assets to a highly optimized `dist` folder.
```bash
npm run build
```

### 5. Preview Production Build
Locally preview the built distribution files.
```bash
npm run preview
```
