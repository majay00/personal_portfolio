# Personal Portfolio

This repository contains the source for a single-page personal portfolio website for Madireddy Veeranjaneyulu.

The site is built as a static frontend project and focuses on presentation, interactivity, and responsive layout. It does not depend on AI services or AI-specific libraries.

## Technology Used

- HTML5
- CSS3
- Vanilla JavaScript
- Vite for local development and production builds
- Google Fonts for typography

## What The Site Does

- Presents a cyberpunk-style portfolio layout
- Shows an animated hero section with typewriter and glitch effects
- Uses a custom particle background
- Adds a custom cursor experience on desktop
- Includes scroll reveal animations and card tilt interactions
- Displays sections for about, skills, projects, education, and contact
- Provides a downloadable resume

## Portfolio Content

The website showcases the following work and background:

- Java Full-Stack development
- SQL and JDBC
- Python programming
- Machine Learning as a showcased skill and project topic
- Web development with HTML, CSS, and JavaScript

The portfolio cards include projects such as:

- Student Companion
- Startup Success Prediction
- Responsive Portfolio

These are portfolio highlights. They are not the technologies used to build this repository itself.

## Project Structure

- `index.html` - Main portfolio page with embedded styles and scripts
- `DSC09192.JPG` - Profile image used in the page
- `m_veeranjaneyulu.pdf` - Resume download asset
- `dist/` - Production build output generated by Vite
- `package.json` - Project metadata and npm scripts

## Run Locally

Make sure Node.js is installed, then run:

```bash
npm install
npm run dev
```

Open the local Vite address shown in the terminal.

## Build For Production

```bash
npm run build
```

## Preview The Build

```bash
npm run preview
```

## Notes

- The portfolio is implemented in a single `index.html` file with inline CSS and JavaScript.
- No frontend framework is used.
- The `dist/` directory is generated output and can be recreated at any time with the build command.
